### `DomainAccessTable` — per-domain access and admin rights (November 2026)

New, built to Figma's `_Accounts_User_Modal_Domain_Access_Table`: a row per domain with an Access checkbox, an Admin checkbox and the Role they add up to (`domainRole`: Admin if ticked, else User if Access, else No Access), shown as a `Tag`. The two boxes are independent and always available. Controlled. Admin's tag is green, as User's, until design settles it.
